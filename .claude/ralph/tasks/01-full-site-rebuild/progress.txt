# Ralph Progress Log

## Codebase Patterns

### Code Style
- ES6 arrow functions ONLY — never use `function` keyword
- All imports at top of file — no inline imports inside functions
- Comments in English only, only when logic is not self-evident
- TypeScript strict mode

### Testing
- Unit tests: Vitest with vi.mock() for Prisma
- E2E tests: Playwright with seeded database
- Test files: colocated with source (*.test.ts for unit, e2e/*.spec.ts for E2E)
- Mock pattern: vi.mock("@/lib/prisma", () => ({ prisma: { model: { method: vi.fn() } } }))
- beforeEach: vi.clearAllMocks()
- Test both happy path and error cases

### Design System
- **MOBILE-FIRST**: All CSS written for mobile first, then md: for tablet, lg: for desktop. NEVER desktop-first.
- Dark navy bg: #0f172a to #1e1b4b
- Accent amber/gold: #f59e0b to #d97706
- Glass cards: bg-white/5 backdrop-blur-xl border border-white/10
- Hover glow effect on interactive elements
- Serif headings: Playfair Display
- Body font: Inter
- Use shadcn/ui components wherever possible
- Touch targets: min 44px on mobile
- Grid: 1 col mobile, 2 col md:, 4 col lg: (for event cards)

### Architecture
- App Router (Next.js 15)
- Server Components by default, 'use client' only when needed
- Server Actions for mutations
- ISR for public pages (revalidate: 3600 for dynamic, 86400 for static)
- revalidatePath() on admin mutations
- Prisma singleton in lib/prisma.ts

### Accessibility (RGAA)
- Skip-nav on every page
- Semantic HTML: nav, main, article, section, footer
- Proper heading hierarchy
- Alt text on all images
- Focus visible on all interactive elements
- Keyboard navigation throughout

### Quality Gates (run before every commit)
- pnpm tsc --noEmit (zero errors)
- pnpm test (all unit tests pass)
- pnpm test:e2e (all E2E tests pass when applicable)
- No console.log in production code
- No unused imports/variables
